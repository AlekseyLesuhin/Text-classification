# Text-classification
Этот обучающий проект наглядно демонстрирует все этапы решения классической NLP задачи классификации текста. В качестве примера взята задача классификации отзывов гостей ресторанов на позитивные и негативные. Набор данных предоставляет собой датасет из отзывов пользователей о ресторане и меткой: 1 - позитивный отзыв, 0 - негативный отзыв.

# Данные
Размер: 22163 записи
Признаки:

    text - отзыв гостя

Целевая переменная: 
    
    label (0/1)

Особенности данных:
    
    Сбалансированный датасет

Проект включает в себя следующие этапы:

    Проверка на корректность и качество данных (файл EDA.ipynb)
    Детальное изучение признаков и таргета (файл EDA.ipynb)
    Препроцессинг данных (файл baseline.ipynb):
        предобработка текстовых данных (приведение к нижнему регистру, удаление лишних пробелов)
    Построение базовых моделей - CountVectorizer и TfidfVectorizer и подсчет метрик (файл baseline.ipynb)
    Построение нейросетевых моделей - RNN, LSTM, CNN, LSTM + GloVe (файл keras.ipynb)

# Решение
## 1. EDA (Исследовательский анализ данных)

 - В датасете 22163 строки, 2 колонки (text - текстовое описание отзыва и label - таргетная переменная 0 или 1)
 - Пристутствуют дубликаты в размере 1448 строк
 - Датасет сбалансирован. Распределение классов - 60%/40%
 - Построена диаграмма распределения количества символов по отзывам. Имеет куполообразную форму и диапазон значений ~ от 2 до 100 символов
 - Построена диаграмма распределения количества слов по отзывам. Диапазон значений ~ от 1 до 15 символов
 - Построен график ТОП самых частых слов (со стоп словами и без)
 - Проведен анализ важности токенов для классификации с помощью ANOVA F-test и построены соответствующие диаграммы
